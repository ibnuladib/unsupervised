# Cognition × Notion Student OS Hackathon

## Context

Hackathon project workspace. Goal: build a practical, functional solution that
improves student life using **Devin** and **Notion Student OS**.

Possible focus areas: academic planning, productivity, student organizations,
career development, or other campus-life challenges.

## Requirements

- Primary development tool: Devin Chat.
- Solution should incorporate Notion Student OS and/or the Notion API
  (see https://developers.notion.com/).
- Must solve a real, meaningful student-life problem and be functional.

## Submission

- Push the project to a **public GitHub repository** with a README covering:
  - What the project does and the problem it solves
  - How Devin Chat was used
  - How the solution incorporates Notion Student OS
  - Instructions for running/testing the project
- Submit via the official Google Form before the deadline (6:00 PM).
- Use the Luma-registered email for submission.
